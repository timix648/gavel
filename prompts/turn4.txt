CONTRACT - add to AuctionHouse:
  bidWithAuthorization(uint256 lotId, uint256 amount, uint256 validAfter,
                       uint256 validBefore, bytes32 nonce, uint8 v, bytes32 r, bytes32 s)
- Callable by anyone (the relayer). The bidder is the signer `from`, never msg.sender.
- Use USDC.receiveWithAuthorization(from, address(this), amount, validAfter, validBefore,
  nonce, v, r, s) - NOT transferWithAuthorization - so a front-runner cannot replay the
  signature to move funds without placing the bid (receiveWithAuthorization requires
  msg.sender == to).
- Then run exactly the same bid logic as bid() for `from` (refactor bid() into an
  internal _bid(bidder, lotId, amount) used by both; keep CEI and nonReentrant).
- Emit RelayedBid(lotId, bidder, relayer, amount).

RELAYER - a small Bun HTTP service in relayer/ (separate from the Vite app):
- POST /bid {lotId, amount, auth:{from,to,value,validAfter,validBefore,nonce}, sig}
- Validates: to == AuctionHouse, value == amount, validBefore in the future, amount is
  the current next valid bid, lot is live. Rejects otherwise with a clear message.
- Submits bidWithAuthorization from a relayer EOA (key from env RELAYER_PRIVATE_KEY,
  never logged) with maxFeePerGas >= 20 gwei and maxPriorityFeePerGas 0 (Arc drops
  transactions below the 20 gwei floor silently), tracks its own nonce, retries once at a
  higher fee if no receipt in 15 s.
- Logs gas cost per relayed bid as gasUsed * effectiveGasPrice / 1e12 (USDC, 6 dp) and
  exposes GET /stats {relayedBids, totalGasUsdc}.
- Per-address rate limit (5 bids/minute) and a daily spend cap so the float cannot be
  drained.
- README section: how to run it, env vars, and hosting options.
