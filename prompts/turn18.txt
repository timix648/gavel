Balanced preset, frontend only.

A. SLIDE TRANSITION (user request: "Open app" / "Bid on a live lot" should behave like a
   slideshow swiping left to reveal the bid pages)
1. Use the View Transitions API through React Router (`viewTransition` on the Link /
   `navigate(to, { viewTransition: true })`, react-router-dom v7). Going FORWARD from
   the landing page into the app (/ -> /lots or /lot/:id) the whole landing page slides
   out to the LEFT while the app slides in from the RIGHT, like a slide deck:
   ::view-transition-old(root) translateX(0 -> -100%) and ::view-transition-new(root)
   translateX(100% -> 0), 550 ms, cubic-bezier(0.32,0.72,0,1), with a slight opacity dip
   on the outgoing page. Going BACK to the landing page (logo click, browser back) slides
   the other way. Set the direction with a data attribute on <html> before starting the
   transition (e.g. data-nav="forward" | "back") and key the CSS off it.
2. Keep the header from jumping: give the nav its own view-transition-name so it
   cross-fades instead of sliding (the landing nav and app nav differ).
3. Inside the app (between /lots, /lot/:id, /create, /me, /proof) do NOT slide; keep the
   current instant navigation.
4. Fallbacks: browsers without document.startViewTransition (Firefox) navigate
   instantly; prefers-reduced-motion = instant, no slide.
5. "Bid on a live lot" lands on the live house lot's page directly (/lot/:id) when one
   exists, else /lots.
